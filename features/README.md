# Cucumber and Playwright Testing

This directory contains Cucumber feature files and step definitions for testing the application using Playwright.

## Screenshot Functionality

The test framework includes automatic screenshot capture for failed tests, as well as the ability to take manual screenshots during test execution.

### Automatic Screenshots on Test Failure

When a test fails, a screenshot is automatically taken and saved to the `features/screenshots` directory. The screenshot filename includes the scenario name and a timestamp.

### Manual Screenshots

You can take screenshots manually in your tests using the following steps:

```gherkin
Then I take a screenshot
```

or with a custom name:

```gherkin
Then I take a screenshot named "my-custom-screenshot"
```

### Using the Screenshot Utility in Custom Step Definitions

You can also use the screenshot utility directly in your custom step definitions:

```typescript
import { takeScreenshot } from "../utilities/screenshot.ts";

// In your step definition
await takeScreenshot(this, "optional-custom-name");
```

## Test Reports

Test reports are generated in the following formats:

- HTML report: `features/reports/cucumber-report.html`
- JSON report: `features/reports/cucumber-report.json`

## Directory Structure

The testing artifacts are organized as follows:

```
features/
├── screenshots/     # Contains all screenshots taken during test runs
├── reports/         # Contains HTML and JSON reports generated by Cucumber
└── ...
```

This organization keeps all testing-related files contained within the features directory.
